# 🌸 AniWave Radio

**Лучшее аниме-радио ВКонтакте (VK Mini App)**

AniWave Radio — это современное веб-приложение для прослушивания японской музыки, саундтреков из аниме и Lo-Fi битов прямо во ВКонтакте. Приложение написано на **React + TypeScript** с использованием дизайн-системы **VKUI**.

## ✨ Возможности

*    **15+ Радиостанций**: J-Pop, Anime OST, Lo-Fi, City Pop, K-Pop и многое другое.
*    **Умный поиск**: Мгновенная фильтрация станций по названию или жанру.
*   ❤️ **Избранное**: Сохраняйте любимые станции (данные сохраняются в LocalStorage).
*   🌙 **Таймер сна**: Автоматическое выключение через 15, 30 или 60 минут.
*   🎨 **Полноэкранный режим**: Стильный плеер "Сейчас играет" с анимированной визуализацией.
*   📱 **Адаптивность**: Идеально работает на ПК и мобильных устройствах внутри VK.
*   ⚡ **Быстрая работа**: Оптимизировано на Vite для мгновенной загрузки.
*   💬 **Чат с сообществом**: Общайтесь с другими слушателями напрямую.
## 🎛️ Эквалайзер и Визуализация

В AniWave Radio встроен полноценный аудио-процессор на базе **Web Audio API**, который позволяет не только слушать музыку, но и управлять её звучанием.

### Особенности:
*   **Real-time Визуализация:** Анимированный спектр частот, который реагирует на музыку в реальном времени. Доступен как в полноэкранном режиме плеера (на обложке станции), так и в настройках звука.
*   **Пресеты звучания:**
    *   🔵 **Плоский (Flat):** Оригинальное звучание потока без изменений.
    *   🔊 **Басы (Bass):** Усиление низких частот для более глубокого и мощного звука (идеально для DnB, Hip-Hop, Metal).
    *    **Вокал (Vocal):** Акцент на средних и высоких частотах для четкости голоса (отлично для J-Pop, City Pop, новостей).
*   **Технологии:** Используется связка `BiquadFilterNode` (для фильтров) и `AnalyserNode` (для получения данных спектра), что обеспечивает минимальную задержку и высокую производительность даже на мобильных устройствах.

> **💡 Совет:** Попробуйте включить пресет "Басы" на станции *SomaFM Metal Detector* или *Full Spectrum DnB* — разница ощутима сразу!

## 🚀 Установка и запуск

Чтобы запустить проект локально, выполните следующие шаги:

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/nekoulik/radio-app.git
    cd radio-app
    ```

2.  **Установите зависимости:**
    ```bash
    npm install
    # или
    yarn install
    ```

3.  **Запустите сервер разработки:**
    ```bash
    npm run dev
    ```

4.  **Откройте приложение:**
    Перейдите по ссылке [http://localhost:5173](http://localhost:5173) в вашем браузере.
